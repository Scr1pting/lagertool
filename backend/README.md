
# BACKEND 2025

A Go-based backend API for an inventory management system ("lagertool") that tracks items, locations, and loans.

## Features

- RESTful API for managing organisations, inventory, carts, loans, and requests
- PostgreSQL database with go-pg ORM, schema created and migrated on startup
- Login via VSETH Keycloak (OIDC with PKCE), session cookie, admin rights from Keycloak roles
- Request messaging system for borrow request communication
- Shelf unit descriptions generated by the `description_gen` service
- Auto-generated Swagger/OpenAPI documentation
- CORS restricted to the frontend origin(s)

## Quick Start

### Prerequisites

- Go 1.25+
- Docker and Docker Compose (for PostgreSQL)

### Installation

1. Clone the repository
2. Copy `.env.example` to `.env` and configure environment variables (see below):
   ```bash
   cp .env.example .env
   ```

3. Start the databases (dev on port 5432, test on 5435):
   ```bash
   docker compose up -d
   ```

4. Install Go dependencies:
   ```bash
   go mod download
   ```

5. Run the application:
   ```bash
   go run main.go                 # add -testdata once to insert test data
   ```

The server will start on `http://localhost:8000`

### Command-line flags

| Flag | Description |
|------|-------------|
| `-testdata` | Insert test data (user 1, organisation "VIS", a shelf, an item, a request) |
| `-noserver` | Only create/migrate the database (and insert test data), don't start the server |
| `-using_auth=false` | Disable auth; overrides `USING_AUTH` |

### Environment Variables

See `.env.example` for the full list.

```env
# Database Configuration
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=example
DB_NAME=appdb

# Description generation service
DESCRIPTION_GEN_URL=http://localhost:8080

# Auth: on unless USING_AUTH=false (local dev without Keycloak only)
USING_AUTH=true
VSETH_CLIENT_ID=
VSETH_CLIENT_SECRET=
OIDC_ISSUER_URL=https://keycloak-fake.vis.ethz.ch/realms/VSETH
OIDC_REDIRECT_URL=http://localhost:8000/auth/eduid/callback
OIDC_POST_LOGOUT_REDIRECT=http://localhost:5173
FRONTEND_URL=http://localhost:5173          # redirect after login + allowed CORS origins
AUTH_ADMIN_ROLES=member-api:admin           # Keycloak client:role pairs granting admin rights
SESSION_SECRET=                             # openssl rand -base64 32
TOKEN_ENCRYPTION_KEY=                       # openssl rand -base64 32 (a different one)
COOKIE_DOMAIN=
COOKIE_SECURE=true
```

## Authentication & Authorisation

- **Login**: `GET /auth/eduid/login` redirects to Keycloak. The callback creates or updates the user, sets `is_admin` from the token roles (`AUTH_ADMIN_ROLES`), grants admins special rights for all organisations, sets an HttpOnly `user_session` cookie and redirects to `FRONTEND_URL`.
- **Requests**: `AuthMiddleware` loads the session from the cookie (401 without one) and refreshes the Keycloak token shortly before it expires. If Keycloak rejects the refresh (user disabled, logged out, token revoked), the session ends. The admin flag is re-read on every refresh.
- **Logout**: `GET /auth/eduid/logout` deletes the session and ends the Keycloak login.
- **Access rules**:
  - `/me/...` routes act on the logged-in user.
  - `/users/:userId/...` routes: that user or an admin.
  - Request messages: the request's author or an admin.
  - Creating/editing inventory and locations, reviewing requests, updating loans and regenerating descriptions: admin only (403 otherwise).
- **Without auth** (`USING_AUTH=false`): every request acts as the user `DEV_USER_ID` (default 1) with admin rights. Never run like this in production.

Tokens stored in the database are encrypted with `TOKEN_ENCRYPTION_KEY`. Without `SESSION_SECRET` / `TOKEN_ENCRYPTION_KEY` the backend falls back to insecure built-in keys and logs a warning.

## API Documentation

Full API documentation is available via Swagger UI at:
```
http://localhost:8000/swagger/index.html
```
To try protected routes there, log in via `http://localhost:8000/auth/eduid/login` in the same browser first.

### Endpoints Overview

#### Auth & current user
| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/auth/eduid/login` | Start the Keycloak login (browser navigation) |
| `GET` | `/auth/eduid/callback` | Keycloak callback, sets the session cookie |
| `GET` | `/auth/eduid/logout` | End the session and the Keycloak login |
| `GET` | `/me` | The logged-in user (`id`, `name`, `email`, `isAdmin`) |
| `GET` | `/me/borrow_requests` | The logged-in user's borrow requests |

#### Resources
| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/organisations` | List all organisations |
| `GET` | `/organisations/:orgId/buildings` | List buildings for an organisation |
| `GET` | `/organisations/:orgId/rooms` | List rooms for an organisation |
| `GET` | `/organisations/:orgId/shelves` | List shelves for an organisation |
| `GET` | `/organisations/:orgId/inventory?start=X&end=X` | List inventory for an organisation |
| `POST` | `/organisations/:orgId/buildings` | Create a new building (admin) |
| `POST` | `/organisations/:orgId/buildings/:buildingId/rooms` | Create a new room in a building (admin) |
| `POST` | `/organisations/:orgId/buildings/:buildingId/rooms/:roomId/shelves` | Create a new shelf in a room (admin) |

#### Items
| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/organisations/:orgId/items/:id?start=X&end=X` | Get a specific inventory item |
| `POST` | `/organisations/:orgId/items` | Create a new inventory item (admin) |
| `PUT` | `/organisations/:orgId/items/:id` | Update an inventory item (admin) |
| `GET` | `/organisations/:orgId/items/:id/borrows` | Get borrow history for an item |

#### Cart
| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/me/cart?start=X&end=X` | Get my shopping cart |
| `POST` | `/me/cart/items` | Add an item to my cart |
| `PUT` | `/me/cart/items/:itemId` | Change an item's amount |
| `DELETE` | `/me/cart/items/:itemId` | Remove an item |
| `DELETE` | `/me/cart/items` | Empty my cart |
| `POST` | `/me/cart/checkout` | Turn the cart into borrow requests (one per organisation) and empty it |
| `POST` | `/me/checkout` | Instant checkout of a single item, cart untouched |

The same cart routes exist as `/users/:userId/cart...` for that user or an admin.

#### Loans & Requests
| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/borrow_requests` | All borrow requests (admin); `?userId=N` for one user (that user or admin) |
| `POST` | `/requests/:id/review` | Approve or reject a pending request (admin) |
| `PUT` | `/requests/:id` | Update a request status (admin) |
| `PUT` | `/loans/:id` | Mark a loan as returned (admin) |
| `PUT` | `/requests/:id/loans` | Mark all loans of a request as returned (admin) |
| `GET` | `/requests/:id/messages` | Get messages for a request (author or admin) |
| `POST` | `/requests/:id/messages` | Post a message to a request (author or admin) |

#### Descriptions
| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/shelf-units/:id/regenerate-description` | Regenerate one shelf unit's description (admin) |
| `POST` | `/shelf-units/regenerate-descriptions` | Regenerate all descriptions (admin) |

#### Search
| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/search/:searchTerm` | Fuzzy search for inventory items |

### Database Schema

Tables are created on startup; new columns are added by the migrations in `db/database.go` (`applyColumnMigrations`), since table creation doesn't change existing tables.

- **organisations**: Organisations that own shelves
- **user**: User accounts (Keycloak subject, encrypted tokens, `is_admin`)
- **session**: Login sessions (random id in the `user_session` cookie)
- **has_special_rights_for**: Per-organisation rights (admins get all organisations)
- **building**: Physical buildings (name, campus, GPS)
- **room**: Rooms within buildings
- **shelf**: Storage shelves owned by organisations
- **column** / **shelf_unit**: Shelf structure (columns containing units, with generated descriptions)
- **Inventory**: Items on a shelf unit (name, amount, consumable flag, keywords)
- **shopping_cart** / **shopping_cart_items**: User shopping carts
- **request** / **request_items**: Borrow requests
- **request_review**: Admin review/approval of requests
- **user_request_message**: Chat messages on requests
- **loans**: Active loan tracking
- **consumed**: Consumed item tracking

## Troubleshooting

### Database Connection Issues

- Verify PostgreSQL is running: `docker compose ps`
- Check database credentials in `.env`
- Ensure database is initialized: `docker compose up -d`

### Login Issues

- "Client not found" on the Keycloak page: `VSETH_CLIENT_ID` is missing or wrong.
- "Invalid redirect uri": the redirect URL (`OIDC_REDIRECT_URL` or `OIDC_POST_LOGOUT_REDIRECT`) isn't registered for the client in Keycloak.
- The frontend's requests fail with CORS errors or don't send the cookie: check that `FRONTEND_URL` matches the frontend's origin exactly.
